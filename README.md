# IP_blacklist_checker_v1
enhanced script with timeout handling and detailed comments in the Excel report for problematic IPs

What it includes:

    Graceful handling of WHOIS timeouts and errors.

    Identifies private/NAT/poorly-registered IPs and notes them.

    Annotates each result with a “Comment” column in the Excel output.

    Adds rate limiting to avoid WHOIS query bans.
